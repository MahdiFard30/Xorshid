# سرویس دوم خورشید: GroqCloud

برای مسیر صدای شخصی (`khorshid.py`)، پاسخ‌گویی اکنون این ترتیب را دارد:

**Gemini → GroqCloud → Ollama → Mock**

Gemini در هر فراخوانی اول امتحان می‌شود. اگر خطای دسترسی، سهمیه، اتصال، سرویس یا پاسخ خالی بدهد، سرویس بعدی امتحان می‌شود. بدون کلید Groq، آن مرحله کنار گذاشته می‌شود. درخواست لغوشده، خطای برنامه‌نویسی و مسدودشدن صریح محتوایی موجب تکرار روی سرویس بعدی نمی‌شوند. ابزارهایی که قبلاً اجرا شده‌اند برای تغییر مدل دوباره اجرا نمی‌شوند.

## واردکردن کلید

روش پیشنهادی، ورود مخفی از ترمینال و تست پیش از ذخیره است:

```bash
.venv/bin/python -m ultimate_khorshid.cli.groq_setup
```

کلید را در اعلان ترمینال بچسبانید و Enter بزنید؛ حروف آن نمایش داده نمی‌شوند. پس از تأیید دسترسی از endpoint فهرست مدل‌ها، فقط کلید Groq در `~/.ultimate-jarvis/config.toml` ذخیره می‌شود؛ تنظیمات و کلید Gemini حفظ می‌شوند. درخواست فهرست مدل‌ها پاسخ متنی تولید نمی‌کند. اگر تست ناموفق باشد، کانفیگ قبلی تغییر نمی‌کند.

فایل `.groq.key` در ریشهٔ پروژه آماده شده است. آن را باز کنید و فقط خود کلید Groq را در آن بگذارید؛ بدون نام متغیر، کوتیشن یا توضیح. ذخیره کنید و خورشید را دوباره اجرا کنید:

```bash
.venv/bin/python khorshid.py
```

این فایل در Git نادیده گرفته می‌شود و هنگام ایجاد، دسترسی آن ۶۰۰ است. کلید را در چت یا کد عمومی قرار ندهید.

متغیر محیطی `GROQ_API_KEY` و تنظیم `engine.groq.api_key` نیز پشتیبانی می‌شوند. هنگام بارگذاری کانفیگ، ENV بر مقدار فایل مقدم است؛ موتور مقدار صریح حاصل را می‌گیرد و فقط در نبود آن به ENV/keyring و سپس فایل محلی مراجعه می‌کند. تست ترمینال دقیقاً کلیدی را که وارد شده می‌فرستد تا کلید قدیمی جای آن را نگیرد. کلید OpenAI برای Groq استفاده نمی‌شود و آدرس مقصد ثابت `https://api.groq.com/openai/v1` است؛ مبنا [مستند اتصال Groq](https://console.groq.com/docs/openai) است.

مدل پیش‌فرض `openai/gpt-oss-120b` است؛ `openai/` بخشی از شناسهٔ مدل میزبانی‌شده در Groq است و درخواست به API شرکت OpenAI فرستاده نمی‌شود. مدل را می‌توان با `KHORSHID_GROQ_MODEL` یا `[engine.groq].model` تغییر داد. [مدل‌های رسمی Groq](https://console.groq.com/docs/models)

## رایگان بودن

GroqCloud پلن Free با سهمیهٔ محدود دارد؛ محدودیت دقیق حساب و مدل در کنسول حساب مشخص است. تمام‌شدن سهمیه معمولاً با ۴۲۹ گزارش می‌شود و زنجیره به Ollama و سپس Mock ادامه می‌دهد. [سهمیه‌های رسمی پلن رایگان](https://console.groq.com/docs/rate-limits)

برنامه پرداخت، خرید اعتبار، ارتقای حساب یا سرویس پولی تازه‌ای فعال نمی‌کند. حساب‌های Gemini و Groq باید روی پلن رایگان باقی بمانند؛ کد از روی کلید API نمی‌تواند تضمین کند حساب از قبل پولی نیست. قیمت مدل در صفحهٔ عمومی به معنی قبض برای حساب Free نیست؛ وضعیت حساب تعیین‌کننده است.

سقف درخواست/توکن رایگان ممکن است از پنجرهٔ Context مدل کمتر باشد؛ یک مکالمه یا فهرست ابزار خیلی بزرگ نیز ممکن است با خطای سهمیه به موتور بعدی منتقل شود. این اتصال سهمیهٔ نامحدود ایجاد نمی‌کند. Mock هم مدل زبانی کامل نیست و فقط قابلیت‌های محدود داخلی دارد.

## گفت‌وگوی صوتی

در نسخهٔ صدای شخصی، اگر رونویسی Gemini در دسترس نباشد و کلید Groq تنظیم شده باشد، فایل ضبط‌شده به رونویسی Groq با مدل `whisper-large-v3-turbo` و زبان `fa` داده می‌شود. سپس متن با زنجیرهٔ پاسخ بالا پردازش می‌شود و همان TTS شخصی خروجی را می‌خواند. Ollama و Mock جایگزین رونویسی صدا نیستند؛ اگر هر دو سرویس رونویسی شکست بخورند، متن ساختگی تولید نمی‌شود.

رونویسی Groq از endpoint رسمی transcription استفاده می‌کند، نه ترجمهٔ صوت به انگلیسی. [مستند رونویسی](https://console.groq.com/docs/speech-to-text)

این تغییر، صدای بومی و نشست `khorshid_live.py` را به Groq تبدیل نمی‌کند؛ آن مسیر همچنان مخصوص Gemini Live است.
