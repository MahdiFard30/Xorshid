# حافظهٔ خودکار خورشید

حافظهٔ خودکار به‌صورت پیش‌فرض روشن است. نیاز به API یا نصب کتابخانهٔ تازه ندارد.
برنامهٔ در حال اجرا را پس از دریافت این تغییرات ببندید و دوباره باز کنید.

## چه چیزی ذخیره می‌شود؟

- متن درخواست و پاسخ، پس از پوشاندن الگوهای شناخته‌شدهٔ کلید و رمز؛ این پوشاندن تضمین تشخیص همهٔ اسرار نیست.
- نام ابزار، آرگومان و نتیجهٔ کوتاه‌شده، با وضعیت واقعی موفقیت/خطا.
- اطلاعات صریح اول‌شخص دربارهٔ نام، شهر و رنگ موردعلاقه، بدون فراخوانی اضافه به مدل. مقدار جدید جای قبلی را می‌گیرد.
- سایر گفته‌ها در سابقه باقی می‌مانند و با جست‌وجوی واژگانی بازیابی می‌شوند؛ استخراج آزاد همهٔ ترجیحات یا آموزش وزن‌های مدل انجام نمی‌شود.

پیش از درخواست بعدی، آخرین ۸ نوبت مکالمه، اطلاعات استخراج‌شده و تجربه‌های مرتبط به مدل داده می‌شود.
پاسخ متنی به‌تنهایی موفقیت کار محسوب نمی‌شود. روش‌های قبلی خودکار اجرا نمی‌شوند؛ مدل باید وضعیت فعلی را بررسی کند.
بهبود سرعت و دقت به مدل و کار بستگی دارد؛ اضافه‌کردن سابقه می‌تواند هزینهٔ توکن ورودی را افزایش دهد.

CLI، خورشید صوتی، هات‌کی و داشبورد محلی از نشست `local` استفاده می‌کنند.
تلگرام برای هر ربات/چت/کاربر دیتابیس جدا دارد و حافظهٔ شخصی دسکتاپ را نمی‌خواند.
سازوکار جداسازی حافظه جای احراز هویت سرور یا محدودیت دسترسی ابزارهای سیستم را نمی‌گیرد.

## تست سریع در ترمینال VS Code

```bash
python -m ultimate_khorshid.cli.main ask "رنگ موردعلاقه من آبی است"
python -m ultimate_khorshid.cli.main ask "رنگ موردعلاقه من چیه؟"
python -m ultimate_khorshid.cli.main memory
python -m ultimate_khorshid.cli.main memory --history
python -m ultimate_khorshid.cli.main memory --facts
python -m ultimate_khorshid.cli.main memory --search "رنگ"
```

## تنظیمات و حذف

این کلیدها را در بخش موجود `[agent]` در کانفیگ مورد استفاده قرار دهید:

```toml
context_from_memory = true
auto_memory = true
history_turns = 8
memory_retention = 1000
```

`context_from_memory = false` خواندن و نوشتن خودکار و ابزارهای حافظه را در درخواست Runtime خاموش می‌کند.
`auto_memory = false` فقط ثبت خودکار درخواست‌های جدید را خاموش می‌کند؛ حافظهٔ قبلی همچنان قابل بازیابی است.
آخرین ۱۰۰۰ نوبت در هر دیتابیس نگه داشته می‌شود؛ نوبت‌های قدیمی‌تر حذف می‌شوند.
حافظهٔ دستی و اطلاعات استخراج‌شده با این محدودیت حذف نمی‌شوند.
دستورات مستقیم مدیریت حافظه حتی هنگام خاموش‌بودن Runtime قابل استفاده‌اند.

```bash
python -m ultimate_khorshid.cli.main memory --clear-conversation
python -m ultimate_khorshid.cli.main memory --forget-all
```

دستور اول فقط سابقهٔ نشست محلی را پاک می‌کند. دستور دوم با تأیید شما همهٔ حافظهٔ محلی را حذف می‌کند.
دکمهٔ پاک‌کردن تاریخچهٔ داشبورد، سابقهٔ نشست محلی را هم پاک می‌کند؛ اطلاعات استخراج‌شده باقی می‌مانند.
برای کانفیگ دیگر: `memory --config path/to/config.toml`.
مسیر `storage.db_path` برای خواندن خودکار، ابزارهای حافظه و مدیریت CLI یکسان است؛ اطلاعات قدیمی حفظ می‌شوند.

## استفاده از پایتون

```python
rt.ask("درخواست", session_id="local")
rt.ask("درخواست بدون حافظه", memory=False)
rt.ask("درخواست کاربر دیگر", session_id="chat-2", memory_scope="trusted-user-2")
```

`session_id` فقط سابقهٔ کوتاه مکالمه را جدا می‌کند؛ جداسازی کامل اطلاعات با `memory_scope` است.
scope باید از هویت تأییدشدهٔ کاربر ساخته شود، نه ادعای دلخواه او.
