# اصلاح مسیر گفتار خورشید

بررسی نمونه: متن پاسخ زیر ۱۵۰۰ کاراکتر و فایل WAV برابر ۲۹٫۷۲ ثانیه است. بنابراین برش ۱۵۰۰ کاراکتری علت این نمونه نیست. محدودیت ۵۱۲ توکن G2P، یکپارچه‌بودن ورودی، پایان‌نیافتن تصادفی تولید و طول صدای مرجع از نقاط قابل بررسی هستند. فایل مرجع my_voice_prompt.wav در اختیار نبود و طول آن در محیط شما باید اندازه‌گیری شود؛ نسخهٔ جدید طول اصلی و طول مورد استفاده را ثبت می‌کند. بدون اجرای مدل واقعی و مقایسهٔ شنیداری، رفع کامل تکرار تضمین نشده است.

این اصلاح:
- عددها را پیش از تقسیم متن به کلمات تبدیل می‌کند.
- متن را پیش از G2P به عبارت‌های کوتاه تقسیم می‌کند و خروجی بدون پایان را رد می‌کند.
- فونم‌ها را با توکنایزر خود مدل به بخش‌های حداکثر ۱۸ توکنی تقسیم می‌کند؛ تا حد ممکن زنجیرهٔ اضافه حفظ می‌شود.
- مدل G2P و Pocket را هر کدام فقط یک بار در هر پاسخ بارگذاری می‌کند.
- نسخهٔ موقت صدای مرجع را به حداکثر ۵ ثانیه محدود می‌کند؛ فایل صدای شما تغییر نمی‌کند.
- خروجی‌های مشکوک به طول بیش‌ازحد یا سکوت را حداکثر سه بار تولید می‌کند. این بررسی تشخیص قطعی تکرار معنایی نیست.
- همهٔ قطعات موفق را به ترتیب و با مکث به هم وصل می‌کند؛ خروجی ناقص جای فایل نهایی نوشته نمی‌شود.
- محدودیت ۱۵۰۰ کاراکتری مسیر پاسخ را حذف می‌کند و مهلت تولید را افزایش می‌دهد؛ پاسخ بلند ممکن است زمان بیشتری لازم داشته باشد.
- متن، فونم و نتیجهٔ بررسی هر بخش را در .tts_debug/latest.json ذخیره می‌کند. این فایل فقط آخرین پاسخ را نگه می‌دارد و محلی است.

## نصب

برنامه را با Ctrl+C ببندید. بسته را در Downloads دانلود کنید:

```bash
cd ~/Downloads/Ultimate-Jarvis-main
source .venv/bin/activate
unzip -o ~/Downloads/khorshid-tts-fix.zip -d .
python apply_tts_fix.py
.tts-venv/bin/python -m pip install soundfile sentencepiece
python khorshid_sun_final.py
```

نصاب پیش از جایگزینی، از فایل‌های قبلی نسخهٔ پشتیبان می‌گیرد. اگر فایل پروژه با نسخهٔ شناخته‌شده فرق کرده باشد، نصب متوقف می‌شود تا تغییرات شما از بین نرود.

پس از نصب همان سؤال دربارهٔ استکهلم را دوباره امتحان کنید. در ترمینال باید `[TTS] Generating ... short chunks` و شمارندهٔ آماده‌شدن بخش‌ها را ببینید. اگر خطا یا تکرار باقی ماند، فایل .tts_debug/latest.json و WAV جدید را بفرستید. اگر WAV بیرون از خورشید درست است ولی هنگام اجرای خورشید تپق دارد، مسئلهٔ پخش را جدا بررسی می‌کنیم؛ این بسته پخش‌کننده را عوض نمی‌کند.

تست‌های انجام‌شده: حفظ ترتیب متن و بودجهٔ بخش‌ها، بررسی نحوی فایل‌ها، و مسیر کامل تولید با مدل شبیه‌سازی‌شده. مدل‌ها و صدای مرجع شما در این محیط موجود نیستند؛ تولید واقعی تست نشده است.
