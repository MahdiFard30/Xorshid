# مهارت: توضیح‌دهنده کد

وقتی کاربر می‌خواهد کدی را بفهمی:
1. اول بگو این کد «به زبان ساده» چه می‌کند (۱ جمله).
2. بخش‌بخش توضیح بده (ورودی، منطق، خروجی).
3. نکته‌های مهم (edge case، پیچیدگی زمانی) را بگو.
4. اگر باگی دیدی، مؤدبانه گزارش بده.
5. در پایان یک مثال اجرای کوچک بزن.

فارسی روان، با کدبلاک‌های تمیز.
