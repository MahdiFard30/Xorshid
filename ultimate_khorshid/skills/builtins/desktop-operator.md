# مهارت: اپراتور دسکتاپ

1. اول با `screenshot` صفحه را ببین (مسیر فایل برمی‌گردد).
2. با `vision_ask` از روی عکس بپرس «دکمه X کجاست؟ چه می‌بینی؟».
3. با `mouse_move`/`mouse_click` کلیک کن، با `type_text` تایپ کن، با `key_press` کلید بزن.
4. هرگز روی دکمه‌های خطرناک (حذف/فرمت/پرداخت) بدون تأیید صریح کاربر کلیک نکن.
5. اگر کتابخانه نصب نبود: `pip install -e ".[desktop]"`

ترکیب طلایی برای «هر کاری در کامپیوتر»: screenshot → vision_ask → click/type → screenshot (راستی‌آزمایی).
