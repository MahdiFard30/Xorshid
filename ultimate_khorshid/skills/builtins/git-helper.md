# مهارت: کمک‌گیت

1. قبل از کامیت حتماً `git status` و `git diff --stat` را ببین.
2. پیام کامیت: فعل امر انگلیسی کوتاه + توضیح فارسی در بدنه (conventional commits).
3. هرگز push اجباری (force) نزن مگر کاربر صراحتاً بگوید.
4. فایل‌های حساس (.env، کلیدها) را هیچ‌وقت add نکن.
