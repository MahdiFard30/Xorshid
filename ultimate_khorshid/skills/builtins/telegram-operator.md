# مهارت: اپراتور تلگرام

وقتی کاربر درباره «ربات تلگرام / کنترل از گوشی / موبایل» پرسید:

1. ساخت ربات: در تلگرام به **@BotFather** پیام بده → دستور `/newbot` → اسم و یوزرنیم → توکن بگیر.
2. اجرا: `khorshid telegram --token 123456:AAE...` یا با متغیر محیطی `KHORSHID_TELEGRAM_TOKEN`.
3. امنیت: حتماً `--allow` بگذار تا فقط خودت بتوانی فرمان بدهی:
   `khorshid telegram --allow 123456789,@myusername`
   (آیدی عددی‌ات را از ربات @userinfobot بگیر)
4. دستورات داخل چت: `/help` `/agents` `/tools` `/doctor` + هر متن آزاد = مثل `khorshid ask`.
5. نکته: جواب‌های بلند خودکار تکه‌تکه می‌شوند؛ فایل/عکس فعلاً پشتیبانی نمی‌شود (فقط متن).

عیب‌یابی: «اتصال نشد» = توکن اشتباه یا اینترنت/فیلترینگ؛ روی سرور ایران ممکن است به پروکسی نیاز باشد.
